# 实体发车铃复刻说明

本项目需要制作电路板、焊接元器件，并连接真实的开关和喇叭。完成后设备可以脱离手机独立播放，安卓应用只用于BLE设置。

## 1. 下载文件并准备材料

- [Gerber生产文件](Gerber_PCB1_2026-10-13.zip)：用于PCB打板。
- [BOM元器件清单](BOM_Board1_PCB1_2026-10-13.xlsx)：采购和焊接以表内型号、数量及封装为准。
- [固件与安卓APK下载页](https://github.com/Lc2007081623/departure-bell/releases/tag/v1.0.0)。

主要硬件为ESP32-C3 SuperMini开发板、NS4168功放电路、FP6298升压电路、单节带保护锂电池、自锁开关、8Ω / 2W喇叭及连接线。开发板、开关、喇叭、电池和配套连接线要一并准备，具体是否包含在采购清单中请核对BOM。此版本没有充电电路，电池充电需另行解决。

## 2. 制作并焊接PCB

将Gerber ZIP上传PCB厂家下单，收到后按BOM和板上位号焊接。注意芯片1脚、二极管方向、电池接口极性，以及功放/升压芯片底部焊盘。

当前提供的是已制作实物的v6生产文件。可编辑EDA工程、完整原理图、外壳和实物照片尚未提供；如果需要更改电路，不能只依靠本说明判断所有原理图细节。

## 3. 接线与供电

电源路径为：**单节锂电池 → 升压5V → SuperMini开发板 → 板载稳压输出3.3V → 功放VCC。** 功放VCC在本项目中使用3.3V。

| PCB网络 / 接点 | 连接目标 |
| --- | --- |
| `+5V` / TP9 | SuperMini的5V供电端 |
| `GND` / TP10 | 开发板GND，共地 |
| `VCC` / TP11 | 开发板3.3V输出，给功放和开关上拉供电 |
| `CTRL` / TP12 | 开发板GPIO4 |
| `LRCLK` / TP1 | 开发板GPIO5 |
| `BCLK` / TP2 | 开发板GPIO6 |
| `SDATA` / TP3 | 开发板GPIO7 |
| `GPIO0` / TP16 | 开发板GPIO0，接板上开关检测电路 |
| CN5 | 两线自锁开关：闭合后经板上电路将GPIO0拉低 |
| CN4（SPK1、SPK2） | 喇叭的两根线，分别接两个输出端 |
| CN6（BAT、GND） | 电池正极、负极，按网络标注核对 |

GPIO0有外部100k上拉至3.3V、1k串联和100nF消抖。GPIO8板载蓝灯由固件设为高电平关闭。其他未用GPIO不用为当前固件增加连接。

接线以**GPIO编号和网络名**为准，不要仅凭不同SuperMini版本的排针位置判断。接入开发板前先测量升压输出约5V；上电后核对VCC约3.3V。

**普通USB连接电脑时先断开电池。** 本板没有USB/电池电源隔离，USB和电池不要同时供电。拔下USB后再使用电池独立工作。

## 4. 直接烧录发布固件

下载并解压 `DepartureBell-firmware-1.0.0.zip`，按其中的README.txt操作。烧录包已包含音频，无需先转换MP3或编译源码。

电脑安装Python和esptool，在解压目录执行（COM3改为实际端口）：

```powershell
python -m pip install esptool
python -m esptool --chip esp32c3 --port COM3 --baud 460800 write-flash --flash-size 4MB 0x0 firmware.ino.bootloader.bin 0x8000 firmware.ino.partitions.bin 0x10000 firmware.ino.bin 0x100000 audio.bin
```

如果无法进入下载模式，按住BOOT，按一下RESET，再松开BOOT。写入完成后，单独按RESET运行程序。

此包适配板载4MB Flash的ESP32-C3，使用自定义分区。需要自行修改源码时，参见[固件编译说明](../README.md#固件构建与烧录)。

## 5. 按实体开关验收

1. 开关OFF上电：保持静音，蓝牙开放约60秒后休眠。
2. 按下自锁开关：随机播放音乐，保持ON超过24秒确认同一曲循环。
3. 解除自锁：音乐停止，对应警示音完整播放一次。
4. 警示结束：功放关闭，蓝牙保留60秒，然后休眠。
5. 保留期间或休眠后再次ON：应恢复播放。警示期间重新ON则先等待警示播完。

安装安卓APK，允许蓝牙权限，保持ON，点击“连接发车铃”。可以调音量、固定选曲、恢复随机和保存设置。设备名为DepartureBell，默认音量75%。详细说明见[安卓应用文档](../android-app/README.md)。

已在制成实物上验证音乐循环、对应警示、BLE控制、设置保存、休眠及唤醒。深睡仅关闭MCU相应功能、功放和蓝牙，升压和开发板仍有静态耗电；这是一套个人DIY方案。
